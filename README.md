# 📌 Overview

Traditional healthcare systems store sensitive patient records in centralized databases that are vulnerable to unauthorized access and tampering.

This project introduces a secure Electronic Health Record (EHR) platform powered by Blockchain technology and Machine Learning to ensure:

- Secure storage of medical records
- Tamper-proof transactions
- Controlled data sharing
- Disease prediction using AI
- Patient privacy preservation

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Abhishek14-3/EHR_System.git

cd EHR_System
```

## Install Python Dependencies

```bash
pip install -r requirements.txt
```

## Start Backend

```bash
uvicorn app:app --reload
```

## Run Frontend

Open

```
index.html
```

or

```
http://localhost:8000
```
